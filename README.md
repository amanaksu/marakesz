# 마라케시 · 카펫 시장

Windows 노트북, iPad, Android 태블릿의 최신 브라우저에서 실행되는 반응형 웹 게임입니다. 설치 없이 같은 기기를 돌려가며 플레이할 수 있고, 파랑 상인을 간단한 AI로 바꿔 1인 플레이도 할 수 있습니다.

## 실행

정적 파일만 사용합니다. 이 폴더를 GitHub Pages, Netlify, Cloudflare Pages 같은 정적 호스팅에 올리거나 로컬 웹 서버의 루트로 지정한 뒤 `index.html`을 엽니다. 서비스 워커 때문에 `file://` 대신 HTTP(S)로 여는 것을 권장합니다.

## 구현한 원작 규칙

1. 차례마다 Assam을 직진/좌/우 중 하나로 돌린 뒤 슬리퍼 주사위(1, 2, 2, 3, 3, 4)만큼 움직입니다. 시장 가장자리에서는 안쪽으로 이어지는 길을 따릅니다.
2. Assam이 상대 카펫에 멈추면, 그 칸에서 변으로 연결된 같은 색의 보이는 카펫 칸 수만큼 해당 상인에게 지불합니다. 돈이 부족하면 가진 만큼 냅니다.
3. Assam에 변으로 맞닿는 두 칸에 2칸 카펫을 놓습니다. 상대 카펫 한 장을 한 번에 전부 덮는 배치는 제한됩니다.
4. 모두의 카펫이 소진되면 보이는 카펫 칸과 디르함을 합산해 승자를 정합니다.

원작은 Dominique Ehrhard의 *Marrakech*입니다. 본 프로젝트는 학습·팬 게임 목적의 비공식 디지털 구현이며, 원작의 이미지나 그래픽 자산을 사용하지 않습니다.

## 범위

- 2~4인 동일 기기 패스앤플레이
- 1인 AI 상대 (3~4인 구성에서 파랑 선택)
- 터치·마우스에 맞춘 반응형 레이아웃, PWA 매니페스트

서로 다른 기기끼리 실시간으로 연결하는 온라인 방/초대 기능은 서버 또는 실시간 동기화 서비스가 필요한 별도 범위입니다.
